# 单题学习头部复核

## 本轮选择

当前数据规则、清单恢复和备份合并已有较完整的自动化覆盖。用户侧最明显的剩余断点是单题学习仍沿用专题头部：进入 Q100 时会同时看到“JavaScript 面试题、共 77 题、整篇阅读时长”，与正文只显示一道题的行为冲突。

本轮因此不增加学习功能和依赖，只调整单题上下文：

- 普通文章头部保持原有专题信息。
- 单题学习头部只显示专注模式、来源专题和当前题号，不展示专题总题数、整篇时长及专题简介。
- 当前题从专题中的 `h2` 提升为单题页面唯一的 `h1`，避免头部与正文重复标题。
- 浏览器标题和 description 使用当前题；分享链接使用不包含学习状态的稳定 `articles/<topic>/#qN`。
- 独立笔记进入清单时仍保留文章标题和简介。
- 学习模式不再重复显示独立笔记的顶部状态按钮，状态推进统一由固定学习栏负责。
