# 后续优化顺序

更新：2026-11-09。以本轮学习流程完善为基础，不新增登录、云同步或复杂复习算法。

已补齐统一搜索相关性、React 基础学习路径和可定位的链接维护清单；路径复用现有 7 项内容，支持只学未读、复习待复习、逐步直接标记、指定步骤起点及全部已读后的完成提示。已复核路径、高频笔记及 6 张历史配图，并增加跨标签页、题内目录和焦点回归。后续按报告处理确认失效的引用，继续逐批复核剩余配图，再根据使用反馈决定是否增加更多路径。

补充 AI 基础、RAG 和 AI Agent 三篇知识笔记，包含自拟练习、适用边界及官方参考来源。复用已有搜索、收藏和学习清单；首页分类也展示只有笔记的分类并进入对应笔记列表，避免新知识只能靠搜索发现。有面试题的首页分类仍进入题库，题库分类不混入纯笔记分类。此次未接入模型服务。

三篇内容继续补充本地可运行的输出结构校验与反例、上下文/应用记忆/微调选型对照、固定 RAG 评估夹具与排查顺序，以及工具结果未知时的状态查询、幂等与恢复案例。练习与工程建议明确标注为自拟，不把示例当作真实模型评测结果；审核和更新日期同步维护。

增加 AI 应用评估笔记，覆盖固定问题集、规则/人工/模型评审的分工、关键词规则误判反例、重复尝试与分维度回归，四篇笔记关联阅读并复用原学习功能。

首页与“我的学习”提供 AI 应用学习路径，将基础、RAG、Agent、评估按四步组织。复用 React 路径的步骤目标、阅读标记、未读/待复习清单、暂停恢复和返回原条目。纯笔记清单无需加载题库目录；原 React 路径地址不变。

新增独立“相关资料”栏目，收录 6 篇工具、工程实践、成长与生活、职场权益资料和 10 张原图。复用发布校验、全文搜索、分类标签、图片预览与静态分享；来源说明明确区分收藏原文、整理内容与可核验的引用。

## 第一优先：把关键交互变成持续回归

已加入 Playwright：Chromium、WebKit、手机 WebKit 视口与 Chromium 开发模式，覆盖清单、备份、资源恢复、跨标签页收藏/状态/清单替换/清空、题内锚点及目录焦点。修复 WebKit 下关闭正文目录时焦点未回到按钮的问题。CI 在部署前运行这些用例，失败时保存截图和 trace。

列表翻页后定位并聚焦新页第一条内容，继续输入搜索词时保持输入框焦点。题库、笔记、资料和学习页清除筛选后，焦点统一返回各自搜索框；即使清除时回到第一页，也可直接继续输入。题库无效学习状态与每页数量回退默认值；未知分类、标签保留显示以便清除，笔记无效集合参数回到“全部”。

学习页批量标记支持只勾选本页部分题目或笔记、全选本页及清空选择。切换列表条件或页码后退出选择，跨标签页更新移出本页的条目取消勾选；操作结果可聚焦，沿用原有撤销、收藏保留和保存失败提示。

勾选入口已整合到学习操作区，顺序学习、随机学习和批量标记统一使用所选范围。空选择禁用开始按钮，退出选择恢复原学习范围；混合题目与笔记清单复用暂停、刷新恢复和来源列表返回。确认导入备份或清空记录后清除临时选择。

已选内容支持展开核对、定位原条目和单独取消，顺序与实际学习清单一致。长列表末尾增加已选数量和返回学习操作入口；定位、取消、返回均提供明确的键盘焦点，沿用跨标签页更新和翻页清除选择的规则。

从列表打开正文后提供“返回原列表”，保留搜索、分类、标签、排序、页码及 React 路径来源。正文内跳转和继续阅读沿用来源，刷新及浏览器历史仍可恢复；分享网址不携带来源筛选条件。

分享链接复制增加等待反馈。切换文章或学习题号后忽略旧请求的成功与失败，连续复制只展示最新请求结果；失败后仍可使用原入口重试或直接复制独立链接。

点击“返回原列表”会在列表准备好后定位并聚焦原条目；原条目不再显示时回到列表顶部。用户在等待期间已聚焦其他控件时保留该焦点。题库、笔记、资料、学习记录和 React 路径均覆盖回归。

页面跳转后的延迟聚焦会尊重用户后续选择，避免立即继续搜索时输入框失焦、结果列表被关闭。

正文延迟加载的首次锚点定位同样保留搜索框、学习底栏等区域的新焦点，避免把保存结果或正在输入的搜索词打断；用户主动切换正文锚点时仍正常定位标题。

界面已移除外部字体导入，使用系统字体，减少网络等待和字体替换引起的布局变化；浏览器回归检查首屏与正文不访问外部字体服务。

本篇目录支持按题号和标题筛选；题号精确匹配，标题支持多个关键词。桌面与手机目录共用筛选条件，包含折叠章节下的小标题；清空后恢复完整目录，筛选不修改正文和学习进度。

学习清单目录支持一键清除关键词与阅读状态筛选，并将焦点返回搜索框；“定位当前项”会清除筛选、滚动并聚焦当前条目，不切换正文或修改进度。阅读页和暂停页均覆盖长清单、键盘及手机视口回归。

全局搜索失败时，“重试搜索”支持点击、触摸和键盘操作；重试期间保留关键词及面板，并将焦点返回输入框，避免 Safari 提前关闭结果或按钮卸载后丢失焦点。回归覆盖连续失败后恢复和方向键选择。

学习记录在注册跨标签页监听后补读一次，页面重新显示或获得焦点时再次合并最新记录，覆盖初始化空隙与后台遗漏通知。补读沿用时间戳合并规则，不覆盖内存中未保存的修改，也不会把读取成功误报成保存成功。

学习清单同样在订阅后及页面恢复时补读：同步其他标签页替换、结束后的清单；存储内容未改变时保留本页尚未保存的临时清单和失败提示。损坏数据不会替换当前清单，回归覆盖临时清单的备份导出。

保存失败和内容加载恢复提示已提供直接备份入口，导出包含内存中的未保存修改与学习清单。回归覆盖下载文件内容、新页面导入恢复、导出失败重试，以及提示变长后底栏不遮挡正文末尾；备份不能代替浏览器成功保存，刷新前仍需确认文件已保存。

学习页和连续学习底栏增加阅读记录的直接保存重试，复用已有合并与损坏数据保护，保留标记时间，不推进清单。保存成功有可聚焦的结果提示；再次失败仍保留备份入口，并与清单保存错误分开呈现。

保存失败期间，后台阅读定位只更新内存位置，不自动清除错误或移走重试按钮；用户主动重试或再次修改记录后才尝试恢复保存。回归使用受控时钟覆盖后台定时定位与重试之间的竞争。

学习清单保存失败也提供原地重试，覆盖临时清单、暂停后恢复和结束状态保存失败。清单错误提示集中展示，保存成功聚焦结果；重试先检查已保存版本，采用其他页面已替换或结束的最新状态，不复活旧清单，不覆盖损坏数据。

导入已增加记录变更预览，确认前不写入；可选择恢复备份清单或保留当前清单。预览沿用实际合并和清理规则，支持取消、旧版备份、保存失败重试，以及预览期间的跨标签页更新。可展开具体记录的变更明细，核对阅读与收藏状态及标记时间，按变更类型和题号、标题筛选，并分页查看；失效内容保留原标识。

## 第二优先：继续完善移动端兼容

单题学习页已区分当前题与来源专题；手机 WebKit 自动测试检查宽度、学习操作、弹窗和恢复流程。仍需手机真机和实际 Safari 验收，重点检查虚拟键盘、安全区域、缩放、弹窗滚动及焦点恢复；模拟器视口不代表真实设备覆盖。

较矮窗口中的学习底栏限制为最多 45% 视口高度，长提示可在栏内滚动；“更多操作”在栏内展开，避免菜单被裁切。横屏回归覆盖正文可用空间、备份、结果弹窗、暂停及页尾遮挡。

横屏和矮窗口下，学习清单的筛选区与列表共用滚动区域，标题与关闭按钮保持可见。定位到末尾条目后可以直接关闭，列表条目铺满宽度。回归覆盖阅读页和暂停页的定位、关闭、搜索与切换题目。
