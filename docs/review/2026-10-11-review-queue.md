# 学习队列与批量标记（2026-10-11）

基于 `a4eef5b` 的学习进度与持久筛选，补充筛选后的阅读入口和批量操作。

## 功能

- 内容类型支持全部、仅题目、仅独立笔记；每页支持 12、24、48 条。
- 支持最近标记、较早标记、题号与标题排序；待复习默认较早标记优先，题号使用自然排序（Q2 在 Q10 前）。筛选、排序和每页数量均保存在 URL。
- 开始学习/复习打开全部匹配内容中的第一项，随机学习从全部匹配内容中抽取，不受当前页限制；空队列不展示这两个入口。
- 本页可批量标记已读或待复习，保留收藏，跳过已是目标状态的内容；本页全部相同时禁用对应按钮。
- 可撤销上次有效批量操作，恢复原状态。已被后续单项操作、其他标签页更新或清空修改的记录不会覆盖；撤销新建记录保留删除时间，防止旧备份恢复批量状态。写入前先合并浏览器保存的较新记录。
- 批量提示与撤销入口放在筛选区下方。移动端筛选两列排列，搜索占整行，操作按钮保持可点击的尺寸。

## 边界

复习排序基于标记时间，没有计算复习到期日或掌握程度；开始入口负责打开内容，不会自动修改阅读状态。撤销令牌只保留于当前学习页会话，刷新、离开页面、导入备份或清空后结束，不改变 v1 备份格式。实际浏览器验收覆盖 Chrome 桌面与窄视口，未替代 Safari 和手机真机验收。
