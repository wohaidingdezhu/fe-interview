# 备份导入预览（2026-10-18）

- 文件通过完整校验后先展示预览，统计预计新增、更新、移除、保留及合并后的记录数；确认前不写入，取消或 Escape 返回导入按钮。
- 预览复用实际记录合并规则，包含清空和删除时间的影响。其他标签页修改后更新预览，确认时仍合并最新记录。
- 可取消勾选恢复清单，只导入记录；备份中的空清单明确提示会结束当前清单。旧版备份始终保留当前清单。
- 保存失败保留弹窗并提供重试，阅读记录未持久保存时不替换清单；已经合并到内存的记录不会因关闭预览回滚。
- 延迟读取文件时只接受最新选择，离开学习页后忽略读取结果。继续沿用现有备份格式，无新增依赖。
