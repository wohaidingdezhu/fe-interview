# AI 知识补充与首页分类入口完善

日期：2026-11-01

## 内容

- `ai-fundamentals`：自回归语言模型、Token、上下文、训练与推理的区别，提示词练习与前端结果验证。
- `rag-basics`：资料分块、检索、引用、权限过滤与检索/生成分开评估，明确现有关键词搜索不等于 RAG。
- `ai-agent-basics`：固定工作流与 Agent 的区分、工具执行循环、重试与幂等、权限及停止条件、MCP 的定位。

三篇内容均为整理与自拟案例，关联 Hugging Face、Microsoft Learn、Anthropic 和 MCP 官方资料。已补齐来源、技术适用范围、审核日期、搜索别名及互相阅读链接；不承诺具体模型效果，不依赖 SDK 示例或模型凭据。

## 已有体验改进

首页原分类集合只取含面试题的文章，只有笔记的分类会被遗漏。现在首页汇总普通内容分类，纯笔记分类进入笔记列表并显示篇数；含题目分类继续进入题库，相关资料仍走独立入口。题库自身的分类仍只显示题目所属主题。

新增内容复用现有正文目录、关联阅读、收藏、学习清单、静态分享和全文搜索，没有增加 AI 对话或执行服务。
