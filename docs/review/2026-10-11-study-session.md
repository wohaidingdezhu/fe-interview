# 连续学习清单（2026-10-11）

基于 `040ee01` 的筛选、排序和学习入口，补齐进入正文后的连续阅读操作。

## 行为

- 开始学习/复习固定当前全部匹配内容的顺序，随机学习从同一清单的随机位置开始。清单不受当前分页限制，标记状态变化不会使顺序跳位。
- 正文底部常驻清单位置、当前项标题、上一项/下一项、标记已读并继续、正文目录、返回原筛选列表及结束清单。
- 直接切换不自动标记；最后一项标记成功后结束清单并返回原筛选、排序、每页数量、分页及关键词。标记保存失败时保留当前阅读位置并提示。
- 清单置于当前标签页的会话存储；刷新保留。会话存储无法写入时继续使用内存状态并提示限制。
- 只保存有效格式的题目/笔记键和学习页查询参数。恢复时按当前目录生成链接和标题，排除失效内容，不信任保存的外部链接。
- 清单目录和正文锚点保留 `study=1`，手机目录使用原生 dialog，关闭后恢复焦点。清单模式替代手机底部普通导航，避免两个底栏重叠。
- 修复验收中发现的历史返回重复控制条：将控制条放到阅读分支之外，避免正文重新挂载时产生重复实例。修复后往返只保留一份控制条。

## 边界

清单记录位置和顺序，不计算复习到期日、掌握程度或自动完成状态。正文仍可自由滚动，批量/单项状态只由用户操作修改；清单标记按钮只作用于栏中列出的项目。会话清单不加入长期 JSON 备份，不跨设备同步，关闭标签页后不保证保留。存储解析最多接受 1000 项，当前目录共有 412 项。真实验收覆盖 Chrome 桌面和窄视口，未替代 Safari 与手机真机验收。

没有新增依赖或后端。生产入口 334.11 kB（gzip 105.13 kB），阅读模块 229.53 kB（gzip 72.46 kB）。
