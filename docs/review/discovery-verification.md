## 本地浏览器性能抽样

- 390 × 844 视口首次全文搜索时，全文索引响应体约 150 KB，本地请求约 10.8 ms；加载后精确题号 Q134 到结果更新约 168 ms（包含自动化命令调度开销）。
- 静态深链接 `articles/interview-coding/#q157` 的本地 DOMContentLoaded 约 72 ms、load 约 76 ms；正文数据传输约 16 KB、请求约 3.1 ms。
- 以上是本机 preview 服务与独立 Chromium 的抽样，不等同真实手机、蜂窝网络或线上访客指标。当前题目目录仍单独加载，全文索引仅在搜索时请求，暂不需要进一步拆分。
- 阅读器代码高亮从默认常用语言集合改为本站实际语言集合；懒加载包从约 105 KB gzip 降到约 72 KB，减少约 31%，JS 关键字高亮和未知语言纯文本降级均有回归覆盖。

## 验证边界

JS 工作台的默认运行和错误显示已做浏览器检查，代码编辑执行由沙箱生成单测覆盖；当前自动化 CLI 对 React 受控文本框的批量输入事件与真实键盘不完全一致，因此没有把该工具限制判作产品缺陷。未逐一检查全部 403 道题的视觉布局。学习记录仍依赖当前浏览器存储，应导出备份以跨设备使用。
