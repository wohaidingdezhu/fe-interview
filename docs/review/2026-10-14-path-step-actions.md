# 路径逐步操作（2026-10-14）

- 路径每一步复用现有学习标记，支持直接收藏、标记已读与待复习；进度和未读/复习入口即时更新，单独标记不创建或替换清单。
- “从这一步开始”仅包含当前步骤和后续内容，沿用路径顺序、暂停地址和已有标记。目录加载失败或步骤缺失时禁用开始操作，末步生成一项清单。
- 步骤操作具有独立的无障碍分组与起点名称，启动说明与现有清单替换说明关联。按钮最小高度 44px，窄屏可换行。
- 沿用现有存储与跨标签页同步；保存失败明确提示记录仅在本次访问有效，没有新增存储格式或依赖。
