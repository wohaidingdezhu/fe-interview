# 学习清单保存恢复与阅读焦点检查

日期：2026-10-28

收尾复核：2026-10-29，保留现有未提交修改，未推送或部署。

## 问题与改进

- 学习清单开始、定位或结束保存失败后，只有错误提示和备份入口，无法直接保存本次访问的清单状态。现在阅读底栏和暂停后的页面都能重试保存；成功显示结果并聚焦，失败仍可备份与再次重试。
- 清单保存沿用现有版本检查：与本页上次读取的存储内容一致才写入；其他页面已经替换或结束清单时，采用最新状态并明确提示，不覆盖新清单、不复活已结束清单。读取失败或数据损坏时，保留浏览器原文和本页内存状态。
- 将分散在首页、题库、学习页和暂停卡片中的清单错误集中展示。阅读记录与清单分别提示，连续学习中两者同时失败时共用备份入口。
- 浏览器回归发现正文延迟加载会把焦点从清单保存结果抢回题目标题。首次锚点定位现在尊重正文外已有的操作焦点；主动切换正文锚点仍正常跳转，保留目录关闭与键盘导航行为。

重试不修改阅读标记、不推进学习清单，也不改变当前网址。没有新增学习模块、账号或云端存储。

## 保留的限制

- 浏览器仍拒绝存储写入时，重试不能代替成功保存，仍需导出备份后再刷新。
- 跨标签页版本保护沿用现有存储比较机制，没有引入跨设备同步。
- 手机视口回归不代替真实设备上的虚拟键盘、安全区域与系统存储限制验收。
