# 阅读记录保存重试（2026-10-28）

- “我的学习”和连续学习底栏提供直接重试保存阅读记录和备份入口，统一提示保存结果。
- 使用已有持久化合并流程重试当前内存数据，不再次修改状态或生成标记时间，合并其他标签页较新的修改。
- 无法读取或损坏的存储仍受保护，重试不会覆盖原文；持续写入失败保留错误与备份操作。
- 保存成功后聚焦结果提示，不切换题目、不推进清单；清单本身的保存错误独立显示。
- 学习页重试成功后清除旧的批量操作失败提示，保留批量撤销记录。

验证：生产构建、类型检查、内容和代码片段校验通过。48 项相关浏览器用例通过，覆盖 Chromium、WebKit、手机 WebKit 视口和 Chromium 开发模式，检查重复失败、跨标签页合并、原标记时间、损坏数据保护、不自动推进、刷新恢复及原有备份、批量撤销和横屏底栏行为。已检查手机保存提示截图。本轮未重跑完整浏览器套件，未进行手机真机验收。
