# 学习清单恢复与目录优化

日期：2026-10-11

## 本轮改动

- 首页和学习页显示暂停的清单，保存最近切换的位置，支持继续、查看和结束；随机开始时立即保存抽中的位置。
- 清单目录提供精确题号、标题/分类关键词、阅读状态筛选，跳转保留固定清单顺序和原序号，不自动改变阅读标记。
- 摘要按实际学习记录统计已读、待复习和未读；正文增加“待复习并继续”，末项标记成功后结束并返回原筛选列表。
- 兼容旧版无位置的清单；失效位置回退第一项有效内容并说明。结束清单后，延迟的定位更新不会重新创建清单。
- 原生弹窗支持 Escape 与焦点恢复，移动端目录内部滚动，长标题完整换行；修复列表项因弹性压缩而截断的问题。

## 验证

- Node 24：123 项测试通过，包含位置校验、旧数据兼容、清单结束、失效回退、精确检索及状态计数。
- 类型检查、生产构建及内容校验通过，生成 26 篇静态文章和首页；无新增依赖。
- Chrome 实测：将 Q1 标记待复习并进入 Q2；搜索 Q1 只显示 Q1；目录跳到 Q10 后保持未读。暂停、刷新学习页、切换首页并刷新，继续入口均恢复第 10/39 项。
- 将 Q10 标记已读后进入 Q11，目录显示已读 1、待复习 1、未读 37。暂停页目录跳到 Q39，标记待复习并返回后刷新，清单恢复入口消失，学习状态保持已读 1、待复习 2。
- 随机学习从新的 36 项未读清单抽到 Q7，立即暂停后恢复卡保留第 6/36 项；桌面清单目录显示同一位置。
- 390×844、320×640 视口无横向溢出，清单导航按钮高度 44px，长目录在弹窗内滚动；Escape 后焦点回到“清单目录”。页面仅有一份学习栏，无控制台错误或警告。

## 边界

清单仍属于当前标签页的会话，关闭标签页后不保证恢复；学习记录备份不包含清单。新清单替换旧清单，内容状态保持。保存失败时只在本次访问有效，阅读标记保存失败会停留当前项并提示。
