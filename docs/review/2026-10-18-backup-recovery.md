# 保存失败时的备份恢复（2026-10-18）

- 连续学习保存失败、清单目录加载失败和全局内容恢复提示旁，直接提供完整备份入口。学习页复用同一导出组件。
- 导出读取当前内存中的学习记录与清单，包含未能持久保存的修改；保持既有 JSON 格式和导入规则，没有新增依赖或存储版本。
- 导出异常明确提示保持本页并重试，成功触发下载后提醒确认文件已保存。用户主动刷新前可先下载备份。
- 底栏根据实际高度为正文预留空间，覆盖长错误提示、备份结果与手机换行，保持正文末尾可见。
- 回归发现 Safari 点击全局搜索结果时，输入框失焦可能先关闭列表，阻止页面跳转。按下结果链接时显式转移焦点，保留点击、触摸和键盘选择；移出搜索区仍关闭结果。
